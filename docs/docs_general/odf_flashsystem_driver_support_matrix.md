# IBM ODF FlashSystem driver support summary

IBM® ODF FlashSystem driver, together with Red Hat OpenShift Data Foundation® \(ODF\), enables connecting and monitoring IBM Storage Virtualize® family storage systems running IBM Spectrum Virtualize® software.

The IBM Storage Virtualize® family storage systems supported by the IBM® ODF FlashSystem driver include IBM FlashSystem 5xxx, 7xxx, 9xxx.

**Note:**

-   IBM SAN Volume Controller® (SVC) is fully supported from IBM® ODF FlashSystem driver version 1.4.1.
-   IBM Storage Virtualize® microcode version 8.4.x includes version 8.4.0.x and higher for both LTS and Non-LTS releases. For more information, see [IBM Spectrum Virtualize FAQ for Continuous Development (CD) Release Model for software releases](https://www.ibm.com/support/pages/node/6409554).
